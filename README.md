# 巡山册 ⛰️

> 原名「爬山趣」，更名《巡山册》。GitHub 仓库名保留 `pashanqu`，旧用户数据自动迁移。

一个以「步步登峰」为核心的登山 Web App —— 收录 **45 座名山**，不只是记录爬山，而是**把每天爬的楼梯变成登顶名山的旅程**。

纯 HTML / CSS / JavaScript 实现，**零依赖、无需构建**，数据保存在浏览器 localStorage 中。

## 独家功能：步步登峰 🧗

把日常爬升（手机健康 App 里的"爬楼"数据，1 层≈3 米）记录到 App，就会沿着**真实山径海拔剖面**前进：

- 6 座挑战山峰梯度：泰山 1545m → 黄山 → 华山 → 峨眉山 → 玉龙雪山 5596m → **珠穆朗玛峰 8848m**
- 途经**真实地标**并逐一打卡点亮：红门 → 中天门 → 十八盘 → 南天门 → 玉皇顶（每座山都有专属路书）
- 智能预测：按你的日均爬升推算**预计登顶日期**
- 登顶生成**中式登顶证书**（姓名/山名/海拔/用时/红章），可下载 PNG 分享
- 攀登履历集章 + 专属成就（云端登顶、8848 俱乐部）

## 跑在 GitHub 上的推荐系统 📡

架构借鉴 [Friend-Circle-Lite](https://github.com/cworld1/friend-circle-lite)（无后端、GitHub Actions 定时计算 → 静态 JSON → Pages 展示）：

- [recommender/generate.py](recommender/generate.py)（纯标准库）每天由 [GitHub Actions](.github/workflows/recommend.yml) 定时运行，多信号加权打分：**真实天气预报**（Open-Meteo，看天推荐）、季节适配、周末/两天线场景、节假日人流预警与错峰推荐、周度热度轮换，生成"今日精选 / 当季最佳 / 周末就出发 / 编辑精选"写入 [api/recs.json](api/recs.json) 并自动提交
- 前端首页实时拉取该 JSON 渲染推荐位（带推荐理由），拉取失败时自动回退到本地计算，离线也能用
- 全程零服务器、零成本，机器人提交记录可在 git 历史中追溯（`recs: 每日推荐更新 …`）

## 其他功能

- **首页**：登山数据总览、高分名山推荐、热门主题（#看日出 #夜爬 #云海…）、最近打卡动态
- **发现**：搜索山名/地区/标签，按难度、地区筛选，按人气/海拔/难度/**离我最近**排序；进入页面自动请求**精准定位**（连续 GPS 取最优精度），定位后每座山的卡片都显示与你的直线距离，未定位时有醒目的"打开定位"引导横幅
- **山峰详情**（45 座名山，含五岳全集与四大佛教名山）：海拔、难度、耗时、里程、风景评分、**距你的直线距离**、SVG 海拔剖面图、登山贴士
- **山灵 · AI 登山搭子**：右下角悬浮球打开对话，说"想看云海去哪""带爸妈休闲爬"即可获得带理由的个性化推荐；支持**语音交互**（🎤 按住说话自动发送、🔊 可选语音播报回复）；首页有山灵每日简报
- **GPX 真实轨迹导入**：在"记录"或"我的"页点 📥 GPX，导入两步路 / 绿野游踪 / 六只脚等 App 导出的 GPX 文件，自动识别对应山峰（名称匹配 + 25km 内位置匹配）、日期、用时与里程，一键转为打卡记录
- **山峰护照**：15 座名山印章墙，登顶盖章（山名 + 日期），未登顶显示待集章
- **登顶打卡**：日期、用时、星级评分、登山心得；成功后满屏彩带庆祝；底部导航中央"+"一键打卡
- **登山手账**：全部打卡记录，支持删除
- **成就系统**：初出茅庐、五岳集邮、雪线之上、海拔收藏家等 8 枚徽章，解锁时弹出金色 Toast
- **我的**：**头像支持上传自定义照片**（自动裁剪压缩为 128×128 存储）或 12 款表情、昵称、签名编辑，同行天数统计、成就墙、**备份导出与导入恢复**（换设备不丢数据）、清空记录（保留个人资料）

## 定位说明

- 使用浏览器原生 Geolocation API（`enableHighAccuracy` 高精度模式），坐标仅保存在本机，不上传任何服务器
- 手机开启 GPS 后精度可达数十米；桌面浏览器依赖 Wi-Fi/IP 定位，误差可能较大属正常现象
- 定位功能需要 HTTPS 或 localhost 环境（GitHub Pages 部署地址满足要求）

## 图片说明

15 座名山的卡片与详情页使用**真实实景照片**，来自 Wikimedia Commons（自由许可），由 [scripts/fetch_photos.py](scripts/fetch_photos.py) 自动检索下载（800px 压缩图，自托管于 `img/`），作者与许可协议逐张记录在 [img/CREDITS.md](img/CREDITS.md)。照片加载失败时自动回退到程序化生成的 SVG 山景插画。

## 运行

方式一（最简单）：直接双击打开 `index.html`。

方式二（推荐，更接近真实环境）：

```bash
cd pashanqu
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 目录结构

```
pashanqu/
├── index.html      # 单页应用外壳 + 底部导航
├── css/style.css   # 全部样式（移动端优先，桌面端居中卡片布局）
└── js/
    ├── data.js     # 15 座名山数据（含五岳）、筛选常量
    └── app.js      # 路由、视图渲染、打卡弹窗、成就系统、SVG 生成
```

## 技术要点

- Hash 路由单页应用（`#/home`、`#/explore`、`#/mountain/:id`、`#/records`、`#/profile`）
- 每座山峰的山景头图与海拔剖面图均为**确定性 SVG 程序化生成**（以山名做种子的伪随机），无任何图片资源
- localStorage 持久化，用户输入均经 HTML 转义防注入

# 山峦册 ⛰️

**一座山峰信息的收集册。** 收录 45 座中国名山的完整档案——海拔、难度、耗时、最佳季节、登山贴士、实景相册、与你的距离，附打卡记录与虚拟登山玩法。

纯 HTML / CSS / JavaScript，**零依赖、零后端、零成本**，托管于 GitHub Pages，数据保存在浏览器本机。

## 山峰收集册（核心）

- **45 座名山档案**：五岳全集、四大佛教名山、道教名山、入门级休闲山、5000 米级雪山与蜀山之王，覆盖华东 / 华北 / 华中 / 华南 / 西南 / 西北 / 东北
- **每座山一页档案**：海拔、难度分级、参考耗时、路线里程、风景评分、最佳季节、登山贴士、程序化生成的海拔剖面图
- **实景相册**：绝大多数山配 4 张实拍（来自 Wikimedia Commons 自由许可，逐张记录作者与许可于 `img/CREDITS.md`），全屏灯箱浏览
- **精准定位**：GPS 高精度定位后，显示每座山与你的直线距离，支持"离我最近"排序
- **看天推荐**：GitHub Actions 每日运行推荐引擎（季节适配 + Open-Meteo 真实天气预报 + 假期人流预警），生成"今日精选 / 当季最佳 / 周末就出发"，写入静态 JSON 供前端拉取——推荐系统本身也完全跑在 GitHub 上
- **驴友视角**：一键跳转大众点评 / 马蜂窝 / 六只脚 / 两步路的该山搜索页，看真实口碑
- **山灵**：内置对话式登山搭子（纯前端规则引擎，离线可用），语音输入、语音播报、带理由的个性化推荐

## 附带玩法

### 打卡手账
登顶打卡（日期 / 用时 / 星级 / 心得）、GPX 真实轨迹导入（自动识别山峰 / 日期 / 用时，兼容两步路等 App 导出格式）、成就徽章、山峰护照印章墙、数据备份与恢复。

### 步步登峰（虚拟登山）
把每天爬的楼梯（1 层 ≈ 3 米）记录进来，沿真实山径海拔剖面向前推进：泰山 1545m → 珠穆朗玛峰 8848m 共 6 座挑战山，途经真实地标逐一点亮，按日均爬升预测登顶日期，登顶生成可下载的中式登顶证书。

## 安装为 APP（PWA）

手机浏览器访问本站：
- **安卓**：点击页面内的"安装"引导
- **iOS**：Safari 分享 → 添加到主屏幕

安装后全屏运行、有独立图标，**离线可用**——山里没信号也能查档案、翻相册、记打卡。

## 运行 / 开发

```bash
cd shanluance
python -m http.server 8000
# 访问 http://localhost:8000
```

或直接双击 `index.html`（离线缓存等 PWA 能力需要 HTTPS / localhost）。

## 目录结构

```
shanluance/
├── index.html                 # 单页应用外壳
├── manifest.json              # PWA 清单
├── sw.js                      # Service Worker 离线缓存
├── css/style.css              # 「山水宣纸」设计系统
├── js/
│   ├── data.js                # 45 座名山数据（单一数据源）
│   ├── photos.js              # 相册清单（自动生成）
│   └── app.js                 # 路由 / 视图 / 山灵 / 步步登峰
├── img/                       # 实景照片与图标 + CREDITS.md 版权记录
├── api/recs.json              # 每日推荐结果（Actions 自动更新）
├── recommender/generate.py    # 推荐引擎（GitHub Actions 定时运行）
└── scripts/                   # 照片抓取 / 相册清单 / 图标生成脚本
```
